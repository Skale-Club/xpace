# Xpace branding

Xpace is the Skale Club app for looking after a PC: disk space, cleaning, drivers and hardware. Its icon is a freestanding
folder with three unequal storage blocks, in icy white and cobalt blue on transparency.
The approved master is icon-source.png (1254 x 1254 RGBA). It has no navy tile or
decorative outer border. Run ./make-icon.ps1 to regenerate Tauri icons and src/logo.png.
The build script tracks the ICO/PNG files and npm run build checks the embedded PE icon.
The Skale Club organization mark is a separate asset.
